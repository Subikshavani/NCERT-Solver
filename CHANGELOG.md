## Release Notes

### Version 0.1.0
**Initial Release** - The foundation of the NCERT AI Solver platform

This is the first release of the NCERT AI Solver, featuring:
- AI-powered question answering using Ollama and Qwen models
- RAG-based retrieval from NCERT textbooks
- Modern web interface built with React and Vite
- Secure authentication via Firebase
- Vector search capabilities with Pinecone
